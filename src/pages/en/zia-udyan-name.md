For visitors to Chandrima Udyan the first confusion is usually about the name. The same place appears in some sources as Chandrima Udyan and in others as Zia Udyan, and the English spelling also varies from source to source. This page sets out how the names relate and what the spelling variants are, so that searches and navigation are easier.

## One park, several names

In the published description of the Dhaka Tourist Police, the same park is referred to as both Chandrima Udyan and Zia Udyan. In other words, these are not two different places; the guidance generally refers to the same park. Which name appears more often changes with the particular source or context.

### What to confirm when the name is in doubt

If you are unsure about the name, the most important thing to confirm is which place is meant. Whether you use Chandrima Udyan, Zia Udyan or any spelling, the visitor's aim is the same: the park on the shore of the lake beside the parliament building in Sher-e-Bangla Nagar. In conversation, mentioning a nearby landmark — the [parliament building](/en/nearby/national-parliament/) or [Crescent Lake](/en/crescent-lake/) — rather than the name reduces confusion.

## The meaning of the word “Chandrima”

In Bengali, “Chandrima” means moonlight or moonshine. The name sits well with the crescent-shaped water body beside the park, Crescent Lake. Knowing this linguistic meaning makes both the Bengali and the English spellings easier to remember.

> The number of spellings, and any claim that one of them is the “official” spelling, is not asserted by this guide. The form you see in local and relevant sources is the safest to use.

### A simple rule for matching spellings

Many apps return results based on how a name is spelled. So if one spelling does not work, it is worth trying the alternatives in turn — first Chandrima Udyan, then Chandrima Uddan, then Chondrima Uddan or Zia Udyan. In Bengali input, try both চন্দ্রিমা উদ্যান and জিয়া উদ্যান. Noting which spelling gives the best result will help you later.

## What to do if a map or search does not find it

- In navigation, first enter “Chandrima Udyan”; if it does not come up, try “Chandrima Uddan” or “Zia Udyan”.
- To type in Bengali, try both “চন্দ্রিমা উদ্যান” and “জিয়া উদ্যান”.
- If an app does not accept the Bengali name, enter the destination using the English spelling; otherwise use the address “Lake Road, Sher-e-Bangla Nagar”.

### Checking the destination pin in the app

In a ride-share or map app, check whether the pin that drops after you type the name lands on the lake shore or in the area beside the parliament building. If the pin lands somewhere else in the city, there is a risk of arriving at the wrong destination while trying to match the name. In doubt, use the reliable map link given in the sources, or tell the driver “Crescent Lake”. The park's address and entrances are set out in the [map and entrances guide](/en/park-map-entrances/).

## Which name to use where

In ordinary conversation, saying “Chandrima Udyan” is understood by most people. But in files, references or specific lists the name “Zia Udyan” also appears. The important thing is this: whichever name you use, make sure that the guidance is referring to the same place.

> When dealing with a service or an institution, if you are unsure about the spelling of the name, check the institution's own description or its official website.

### When asking local people

When asking local people for directions, saying “Chandrima Udyan” or “Crescent Lake” is usually most useful. Many people know the parliament building, so “the park beside the parliament building” also works. Some people recognise the name Zia Udyan too, but who recognises which name varies by person and context — so keep both names ready.

## Common mistakes with the name

- Assuming Chandrima Udyan and Zia Udyan are two different places — the guidance generally refers to the same park.
- Trying to match a written spelling exactly — the spelling can vary from place to place.
- Not checking the map pin — an easy way to arrive at the wrong destination.
- Assuming you know which spelling is the “official” one — it is not safe to assume this without checking.

## Matching the name in other sources

When matching a name in a document, a booking or a list, it is worth checking the address or the coordinates given alongside it. Seeing a different spelling for the same park is nothing to worry about — it is not unusual. In institutional correspondence, using the institution's own spelling reduces misunderstanding; if in doubt, check the institution's website or the information it provides.

## In short

Chandrima Udyan and Zia Udyan are two common names for the same park, and the English spelling varies too. “Chandrima” means moonlight. If one spelling does not work on a map or in a search, trying another spelling and the alternative name is the most practical solution.
